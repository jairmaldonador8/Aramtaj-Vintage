# Aram Taj — logo package

Fuente: PNG blanco 2016×634 del tema actual de Shopify (`source-original-shopify.png`).
Vectorizado con potrace (`vectorize.py`): alfa × luminancia para eliminar el halo gris
del export original, supermuestreo 4×, trazado con curvas.

## Archivos
- `svg/` — vector maestro. `aramtaj-logo` (completo), `aramtaj-wordmark` (solo ARAM TAJ). Sin sufijo = `currentColor`.
  Variantes: `-ink` #100D0B · `-arena` #DAC293 · `-marfil` #EFE6D6 · `-white`.
- `png/` — transparentes a 240/480/960/1920/3840 px de ancho, por color.
- `social/` — OG 1200×630 (ónix y marfil).
- Isotipo, favicon e íconos: ver `../isotipo/`.

## Uso
- Tamaño mínimo del logo completo: 120 px de ancho (debajo, usar wordmark o monograma).
- Área de respeto: la altura de la "A" de ARAM alrededor.
